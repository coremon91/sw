# 로고 라이브러리와 레이어 일괄 ON/OFF

통합 CG 스튜디오를 새로고침하면 사용할 수 있습니다.

## 로고 선택

1. **상단 로고** 레이어를 엽니다.
2. **KBC 로고 포맷**에서 정지 또는 움직이는 로고를 선택합니다.
3. 중앙 PVW에서 확인하고 위치·크기·불투명도를 조절합니다.
4. **선택 TAKE** 또는 왼쪽 일괄 ON 버튼으로 출력합니다.

선택 시 이미지와 원본 비율 크기만 프리뷰에 적용됩니다. 기존 위치를 유지하되 화면 밖으로 나가는 큰 로고는 안쪽으로 옮깁니다. 직접 URL 입력도 가능합니다. 원본 소재의 투명도는 보존되며 UHD에서도 같은 내부 CG 합성 경로를 사용합니다. SD 크기 원본의 해상도가 UHD 수준으로 높아지는 것은 아닙니다.

`Z:\Nodecg\KBC로고 모음`의 433개 파일을 중복·연속 프레임별로 정리해 23종(정지 20종, 움직이는 로고 3종)을 등록했습니다. PNG/TGA/TIFF는 투명 PNG, VRV와 TGA 시퀀스는 반복 Animated WebP로 변환했습니다. 원본 파일은 변경하지 않았습니다. TIFF의 지정되지 않은 네 번째 채널도 알파로 복원했습니다. SBS LIVE VRV 351프레임은 동봉 TGA와 전체 픽셀 일치를 검사했습니다. UHD VRV의 끝 투명 run이 128픽셀 부족한 프레임은 해당 끝 패턴만 복원하고 동봉 308·310 PNG의 알파와 일치를 확인했습니다.

### 편집 포맷의 제한

- T2P/T2S/T2ST는 Tornado 편집 프로젝트이므로 직접 재생하지 않습니다. 동봉 이미지와 애니메이션을 선택하는 방식이며, 프로젝트의 효과·좌표·좌우 배치는 재현하지 않습니다.
- TAD 2개는 동봉 TGA 시퀀스로 제공합니다. TAD 자체 타이밍은 검증하지 않았습니다. `h` 폴더의 30프레임은 별도 짧은 반복 로고로 등록했습니다.
- HDR 장면의 `kbc sbs uhd hdr.tga` 원본은 폴더에 없어 미등록입니다.
- `SBS UHD`, `SBS UHD LIVE`, 자막 가이드는 넓은 캔버스에 픽셀이 있어 원본 전체 내용을 보존했습니다. 목록 썸네일에서 로고가 작게 보일 수 있습니다.
- 로고 이름에 UHD가 있는 것은 디자인 구분입니다. HDR 색공간 출력 지원을 뜻하지 않습니다.

목록의 **가져오기 결과 / 편집 포맷 안내**에서 원본 파일별 변환 내역을 열 수 있습니다.

## 여러 레이어 ON/OFF

레이어 이름 왼쪽 체크박스는 **일괄 ON/OFF 선택**, 오른쪽 PVW 체크박스는 **프리뷰 표시**입니다. 켜려는 레이어 여러 개를 왼쪽에서 체크한 후 **체크한 N개 ON**을 누르세요.

**체크한 N개 OFF**를 누르면 같은 체크 목록의 레이어만 끕니다. 설정창을 열지 않았거나 편집 문구가 비어 있어도 OFF할 수 있습니다. 입력 내용과 PVW 표시는 유지되므로 OFF 후에도 편집 프리뷰에는 보일 수 있습니다. 실제 출력은 목록의 ON/OFF 또는 **현재 CG** 화면에서 확인하세요.

열어 둔 설정창은 입력 중인 최신 값, 아직 열지 않은 설정창은 저장된 프리뷰 값을 사용합니다. 선택하지 않은 레이어와 쌓는 순서는 유지합니다. 선택 목록은 현재 화면에서만 유지하며 새로고침하면 해제됩니다. 한 번의 클릭으로 각 레이어 ON 요청을 보내며, 동일 영상 프레임에 대한 원자적 전환을 보장하는 기능은 아닙니다.

설정 연결이나 자연재해 문구 검증이 실패하면 ON을 시작하지 않습니다. 프리뷰 준비 오류도 전체 ON을 막습니다. ON 명령 일부만 실패하면 해당 레이어 이름을 표시하므로 목록의 실제 ON/OFF를 확인하세요.

## 검증 / 재설치

격리한 9091 시험 서버에서 7개 레이어 일괄 ON, 최신 입력 반영, 비선택 레이어 유지, 빈 자연재해 문구 차단, TIFF·WebP 표시, 프리뷰와 실제 CG 분리를 확인했습니다. 실제 9090 송출의 TAKE/OUT은 시험하지 않았습니다.

`tests/logo_library_tests.py`(Pillow 필요), `tests/studio_batch_tests.cjs`, `tests/studio_layers_tests.cjs`로 변환 결과와 실패 처리·기존 레이어 분리를 검사합니다. 소재를 다시 가져올 때는 Pillow가 설치된 Python으로 `scripts/import-logo-library.py 원본폴더 integrations/nodecg/broadcast/graphics/logo-library`를 실행하고 `scripts/install-broadcast-layout.py Z:/Nodecg`로 반영합니다. 설치기는 변경 전 파일을 백업하고 서버 확장·기존 재난 소스를 보존합니다.
