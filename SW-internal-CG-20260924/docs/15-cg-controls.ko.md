# 통합 CG 운용 기능 확장

## 날씨 5초 자동 조회

API 키가 등록되어 있으면 서버가 5초 간격으로 6개 도시의 기온·날씨를 조회합니다. 성공한 데이터는 프리뷰와 송출에 자동 반영하며 ON/OFF, 위치, 크기, 도시 전환 주기는 유지합니다. 조회가 진행 중이면 다음 요청을 건너뜁니다. 하나라도 실패하면 마지막 정상 데이터를 유지하고 다음 주기에 재시도합니다. 새 관측값이 발표되지 않았으면 숫자는 그대로일 수 있습니다.

자동 데이터 갱신은 도시 순환 타이머를 초기화하지 않습니다. 맑음·비/소나기·흐림/구름 많음·눈은 새 투명 PNG 아이콘으로 표시합니다. `graphics/images/weather-v2`에 내장 image_gen으로 제작한 원본 4장과 생성 프롬프트가 있습니다. 수동 날씨는 다음 자동 조회 성공 시 대체됩니다.

## 첨부 위치 가이드

통합 스튜디오의 프리뷰 위 **위치 가이드** 그림을 클릭하면 첨부된 1920×1080 배치도를 프리뷰 바탕으로 켜거나 끕니다. 표시 상태는 해당 브라우저에 저장됩니다. **현재 CG** 모드에서는 숨기며, SW 합성 그래픽에는 가이드 파일을 포함하지 않으므로 송출되지 않습니다.

**상단 로고 → 첨부 가이드 위치 맞춤**은 우측 상단의 가로 파란 영역(X 1601, Y 72, 너비 223, 높이 48)에 로고를 원본 비율로 배치합니다. 프리뷰에 적용한 후 TAKE로 송출합니다. 다른 레이어의 좌표는 바꾸지 않습니다.

## 통합 날씨 지역과 수치 조절

자동 조회 지역은 `전남광주특별시` 하나로 표시하며, 광주·목포·여수·순천·나주·광양 6개 도시를 순환합니다. 기존 광주광역시/전라남도 설정과 조회 요청도 이 통합 그룹으로 연결됩니다. 기존 기온과 ON/OFF 상태는 유지하며, API 새로고침 성공 시 6개 도시 관측값을 받아옵니다. API 키가 없으면 기존 수동 입력을 사용합니다.

레이어 설정의 숫자는 슬라이더 드래그와 직접 입력을 함께 지원합니다. 로고/헤드 위치·크기·불투명도, 날씨 주기·글자·여백·너비·온도, 자연재해/재난 속도, 선거 수치와 사진 조절에 적용됩니다. 두 입력은 같은 값을 사용하며 저장값을 다시 읽거나 프리뷰에서 로고를 이동해도 함께 갱신됩니다. 입력 중 빈 값과 범위 밖 값은 적용하지 않으며, 입력을 마치면 허용 범위로 보정합니다. 프리뷰 적용과 TAKE/OUT의 기존 동작은 유지됩니다.

## 다중 레이어 OFF

레이어 왼쪽 체크박스로 여러 레이어를 선택하고 **체크한 N개 OFF**를 누릅니다. ON과 같은 선택 목록을 사용합니다. 선택하지 않은 레이어, 입력 내용, PVW 체크는 유지됩니다. 빈 문구나 미완성 편집이 있어도 OFF할 수 있습니다. 실제 출력 상태는 레이어의 ON/OFF 및 **현재 CG**에서 확인하세요.

## 날씨 API 키

**날씨 CG → 기상청 API 인증키 → API 키 저장**에서 공공데이터포털의 기상청 인증키를 입력합니다. Encoding/Decoding 형태를 모두 받습니다. 저장 후 **기상청 API 새로고침**을 눌러 선택한 지역의 조회 결과를 확인합니다. 저장 성공은 인증 성공과 다르며, 실제 조회 결과가 정상이어야 유효한 키입니다.

키는 NodeCG 서버의 `cfg/my-cg-weather-key.json`에 저장합니다. 화면에는 저장 여부만 표시하고 키 값을 다시 전송하거나 Replicant에 넣지 않습니다. 저장된 키는 기존 bundle config / 환경변수 / 과거 설정에서 읽은 키보다 우선합니다. 키 저장과 날씨 새로고침은 현재 송출을 자동 변경하지 않으며, 갱신한 날씨는 미리보기 확인 후 TAKE합니다.

최초 설치 시 `scripts/install-weather-api.py Z:/Nodecg` 실행 후 NodeCG 재시작이 필요합니다. 이후 화면에서 저장한 키는 재시작 없이 사용됩니다. `install-broadcast-layout.py`는 UI/그래픽만 설치하며 날씨 서버 확장은 별도로 설치합니다.

## 프로그램 헤드 이미지 파일

**프로그램 헤드 → 내 PC에서 이미지 추가**로 PNG/JPG/WebP/GIF/SVG 파일(최대 20 MB)을 선택합니다. 파일은 NodeCG `assets/my-cg/program-head`에 고유 이름으로 저장되고 선택 목록에 원래 파일명이 표시됩니다. 파일 선택은 프리뷰에만 반영하며, **선택 TAKE** 또는 일괄 ON으로 출력합니다.

X 위치·아래 여백·너비·높이·불투명도를 조절할 수 있습니다. `MORNING WIDE 기본 헤드` 파일이 포함되어 있고, 기존 텍스트 모드도 유지합니다. 투명 PNG/WebP/SVG를 사용할 수 있으며, 재난바가 켜져 있으면 기존처럼 위로 배치됩니다. TIFF/TGA/VRV는 브라우저용 이미지로 변환 후 사용하세요.

## 자막 동시 선택

세 입력란을 모두 펼쳤습니다. **키워드 자막 출력 / 리포트 자막 출력 / 인터뷰 자막 출력**을 각각 체크하고 **미리보기 → 선택 TAKE**로 반영합니다. 종류 체크만으로 현재 송출이 바뀌지는 않습니다.

키워드는 좌상단, 인터뷰는 하단에 표시합니다. 리포트와 인터뷰의 자막바는 같은 X 위치·아래 여백·너비·높이를 사용합니다. 둘 다 체크하면 같은 위치에 겹쳐지며 인터뷰가 앞에 표시됩니다. 기존 재난·자연재해 바의 높이도 함께 반영합니다. 프로그램 헤드는 별도 레이어입니다. 체크를 모두 해제하면 표시되는 자막 내용이 없으며, 자막 레이어 자체는 **선택 OUT**으로 끕니다.

## 검증

격리된 9091 서버에서 다중 OFF의 선택 범위, 세 자막 동시 출력, 파일형 헤드 PVW/TAKE, 업로드 API의 원본 바이트 보존, API 키 저장·입력란 비우기를 확인했습니다. API 인증키의 실제 기상청 조회는 사용자 키로 확인해야 합니다. 자동 시험은 모의 API 응답으로 키 인코딩·저장·재시작 후 읽기·저장 실패·PGM 보존을 검사했습니다.

내부 CG UHD 2160p59.94 시험에서 TAKE/OUT, PVW/PGM 분리 및 연결 끊김 시 CG 제외가 통과했습니다. 하드웨어 출력은 열지 않았습니다.
