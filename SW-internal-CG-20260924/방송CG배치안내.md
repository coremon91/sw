# 방송 CG 배치 변경 — 2026-09-28

참고: [KBC 모닝와이드 2026-09-23](https://www.youtube.com/watch?v=A8BAEkXwJ-Y). 00:52 프로그램 헤드 단독, 01:02 좌상단 키워드, 01:22 및 02:07 이름·발언 자막을 확인했습니다. 파란색 리포트형은 사용자 요청 색상으로 구성했으며 해당 영상 시간대와의 정확한 일치는 아직 확인하지 못했습니다.

- 하단 자막 제어 패널을 **1. 프로그램 헤드 / 2. 자막**으로 분리했습니다. 좌측 하단 주황색 MORNING WIDE는 **헤드 TAKE / 헤드 OUT**으로 독립 제어합니다. 두 줄 프로그램명을 수정할 수 있습니다.
- 자막 종류는 세 가지입니다. **키워드**는 좌상단 주황색 짧은 문구, **리포트**는 하단 파란색 바와 흰색 글자, **인터뷰**는 이름·직함/소속 표식과 하단 흰색 발언 바입니다. 리포트와 발언은 최대 두 줄이며 긴 글은 축소 후 넘치는 부분을 생략합니다.
- 내용을 편집한 후 **미리보기 → TAKE**로 적용합니다. 자막은 한 번에 한 종류를 표시하고 **자막 TAKE / 교체**로 교체합니다. **자막 OUT**은 프로그램 헤드에 영향을 주지 않으며 **헤드 OUT**도 자막을 유지합니다. 편집 미리보기는 송출 상태와 별개입니다.
- **3. 자연재해 스크롤바**를 추가했습니다. [태풍 바비 참고 영상](https://youtu.be/-TuRVFJLoEs)의 시작 구간처럼 파란색 `kbc 자연재해` 표식과 흰색 바·검은 글자로 구성했습니다. 문구를 줄바꿈으로 나누어 입력하면 구분점을 넣어 오른쪽에서 왼쪽으로 반복합니다. 속도는 40~240px/초로 조절하며 **스크롤 미리보기 / 스크롤 TAKE / 스크롤 OUT**으로 독립 제어합니다. 문구는 직접 입력하며 자동 재난 정보 수집 기능은 없습니다. 초기 문구는 비어 있고 OFF이며 빈 문구 TAKE는 차단합니다.
- 우상단은 흰색 KBC 문자 로고입니다. 기존 기본 NEWS 이미지와 좌하단 배치는 새 프리셋으로 표시합니다. 별도 이미지 URL을 지정했다면 해당 이미지는 유지됩니다. 로고 패널에서 이미지 URL과 위치·크기를 계속 조절할 수 있습니다.
- 날씨는 우하단의 아이콘, 지역명, 기온, 한국 시간(HH:mm)으로 표시합니다. 기존 지역 순환·기상청 조회·수동 입력·TAKE/OUT 기능을 유지합니다. 기온 단위는 섭씨이며 영상처럼 숫자만 표시합니다. 시계는 날씨 CG와 함께 켜지고 꺼집니다.
- 재난 CG 파일·내용·위치·동작은 유지합니다. 재난 표시 중에는 새 자막바와 날씨만 재난바 위로 이동하고, 재난 OUT 후 원위치로 돌아갑니다. 선거 CG도 변경하지 않았습니다.

자연재해 스크롤바는 전체 폭 1920px, 높이 72px, 아래 여백 32px입니다. 기존 재난 CG와 동시 표시하면 기존 재난바 위로 이동하고 프로그램 헤드·하단 자막·날씨도 두 바 위로 이동합니다. 각각 OUT하면 남은 CG에 맞게 배치가 복원됩니다. 프로그램 헤드·자막·자연재해 스크롤은 서로의 TAKE/OUT 상태를 바꾸지 않습니다.

모든 배치는 기존 1920×1080 CG 좌표계이며 UHD에서는 같은 비율로 2배 확대됩니다. 프로그램 헤드는 왼쪽 104px / 아래 110px / 높이 140px, 하단 자막은 왼쪽 248px, 키워드는 X 104px / Y 76px입니다. 회사 로고는 X 1710px / Y 76px, 날씨는 오른쪽 112px / 아래 110px가 기본입니다. UHD에서 CG를 네이티브 4K로 다시 그리는 방식은 아닙니다.

## 적용

`Z:\Nodecg\bundles\my-cg`에 설치했습니다. SW **CG · NodeCG** 탭에서 **연결 / 새로고침**을 눌러 대시보드와 내부 렌더러를 다시 읽으면 적용됩니다. 서버나 SW 실행 파일 교체는 필요하지 않습니다. 기존 자막 데이터와 TAKE/OUT 상태는 유지합니다. 새 프로그램 헤드는 최초 OFF 상태이므로 필요할 때 **헤드 TAKE**를 누르세요. 기존 제목은 새 자막을 TAKE하기 전까지 기존 흰색 바 형태를 유지합니다.

카드 없는 내부 CG 합성용 제어입니다. SW의 **CG PVW**에서 확인한 뒤 **CG ON**으로 최종 영상에 합성합니다. 자막/헤드 TAKE는 NodeCG 상태를 변경하며, 외부 CasparCG 출력을 시작하는 명령은 보내지 않습니다.

이전 프리셋 값은 화면에서 새 기본값으로 해석합니다. 새 대시보드에서 값을 적용하면 `layoutVersion: morning-v1`과 함께 저장하여 이후 사용자 위치·크기 변경을 유지합니다.

설치 전 파일은 `Z:\Nodecg\logs\broadcast-layout-backup-*`에 백업되며, `manifest.json`에 변경 파일과 기존 파일 존재 여부를 기록합니다. 다른 SW 패키지에서 재설치하려면 `python scripts/install-broadcast-layout.py "Z:\Nodecg"`를 실행하세요.

검증: 독립 NodeCG 시험 서버(9091)에서 세 자막형 렌더링, 헤드/자막 TAKE·OUT 독립성, 미리보기와 송출 분리, 새로고침 후 편집 내용 복원을 확인했습니다. `node tests/caption_controls_tests.cjs`에서 기존 데이터 읽기·미리보기 격리·세 종류 교체·상호 독립 TAKE/OUT 회귀 검사를 수행합니다. 이전 배치 검증에서 우상단 로고, 날씨 순환·시계, 재난 동시 표시도 확인했습니다. 재난 및 서버 확장 코드의 SHA-256은 설치 전후 동일한지 검사합니다. 이번 변경에 대한 실제 SDI 송출 시험은 수행하지 않았습니다.

자연재해 추가 검증: 같은 독립 서버에서 스크롤 렌더링, 미리보기 격리, 인터뷰 자막 및 기존 재난 CG와의 동시 표시, 독립 OUT을 확인했습니다. `node tests/natural_disaster_tests.cjs`는 빈 문구 차단, 스크롤 방향·반복·속도, 다른 CG 상태 보존, 동시 배치와 OUT 후 복귀를 검사합니다. 자연재해는 기존 내부 CG 렌더링 경로에 포함되어 별도 서버 재시작이나 실행 파일 교체가 필요하지 않습니다.
