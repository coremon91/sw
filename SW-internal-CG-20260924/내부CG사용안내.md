# SW 0.3 — 카드 없는 내부 NodeCG 합성

NodeCG 그래픽을 SW가 투명 RGBA 영상으로 렌더링하고 GPU에서 영상 위에 직접 합성합니다. **CG용 SDI 카드, Fill/Key 배선, CasparCG가 필요하지 않습니다.** CG는 네 개의 영상 입력 슬롯과 별도로 처리됩니다.

```text
영상 파일 → SW 내장 플레이어(INPUT 4) ─┐
선택한 카메라 입력(INPUT 1~3) ─────────┼→ SW GPU → PGM / PVW 화면
NodeCG → 투명 HTML 렌더러(RGBA) ───────┘        → 선택한 SDI 출력
```

## 시작

1. `START-SW.cmd` 또는 `sw_switcher.exe` 실행. 상단 **내부 NodeCG · 카드 없음**이 기본 선택입니다.
2. **CG · NodeCG** 탭에서 대시보드에 연결합니다. 서버가 꺼져 있으면 **NodeCG 시작**을 누릅니다. 기본 위치는 `Z:\Nodecg`, 기본 주소는 `http://127.0.0.1:9090/dashboard/`입니다.
3. **플레이어** 탭 → **SW 파일 입력 · INPUT 4 직접 연결** → 파일 열기. 파일에 맞는 세션 규격을 선택합니다.
4. 스위처의 **내부 재생 / 합성 · SDI 출력 선택**에서 OUT 1(PGM)과 OUT 2(PVW)를 지정한 뒤 **세션 시작**. 둘 다 **출력 사용 안 함**이면 카드 없이 화면에서만 확인합니다. 플레이어에서 재생하고 INPUT 4를 PVW로 선택한 뒤 CUT/AUTO로 PGM에 올립니다.
5. NodeCG 패널에서 자막 등을 편집하고 **TAKE**. 상단 **CG PVW**로 미리 확인한 뒤 **CG ON · PGM**으로 최종 영상에 표시합니다.
6. **CG OFF · PGM**은 전체 CG의 PGM 합성을 해제합니다. NodeCG 패널의 **OUT**은 해당 자막·그래픽만 퇴장시킵니다.

자막, 선거, 재난 경보, 로고, 날씨를 함께 렌더링하며 기존 CasparCG 10~14 레이어와 같은 순서로 쌓습니다. 탭을 바꾸거나 대시보드를 가려도 별도 렌더러와 영상 엔진은 계속 동작합니다. CG 데이터가 실제 PGM에 나가는 조건은 해당 그래픽 TAKE와 상단 CG ON이 모두 활성화된 경우입니다.

## 영상과 출력 선택

- 카드 없는 모드에서는 영상·CG를 SW의 PGM/PVW 화면에서 확인합니다. 미사용 입력은 비어 있는 배경으로 처리합니다. PC 스피커 오디오 모니터링은 기존 버전과 마찬가지로 지원하지 않습니다.
- **내부 재생 / 합성**에서도 OUT 1(PGM)과 OUT 2(PVW)를 각각 지정할 수 있습니다. 하나만 사용하거나 둘 다 생략해도 됩니다. 두 출력에 같은 포트를 중복 지정할 수 없으며, 출력 포트는 선택한 HD/UHD 세션 규격을 지원해야 합니다. 변경하려면 세션을 정지하고 포트를 선택한 뒤 다시 시작하세요. 선택한 출력은 내부 재생 모드 전용 설정으로 저장됩니다.
- 카메라 SDI 입력도 필요하면 **SDI 선택 연결 · 미사용 포트 생략**을 선택하고 필요한 카메라와 출력만 지정합니다. 파일 재생 + 내부 CG에는 CG 수신 포트가 필요하지 않습니다.
- 원본 4Kplayer 실행 파일을 포함한 탭도 유지합니다. 원본 EXE 자체의 영상 전달은 기존 SDI 방식입니다. 완전히 카드 없이 재생하려면 기본 선택인 **SW 파일 입력**을 사용합니다. 이는 기존 플레이어의 FFmpeg 런타임을 사용하는 SW 내부 재생 경로입니다.
- 세션 포맷은 기존 HD 1920×1080i59.94 또는 UHD 3840×2160p59.94입니다. 영상 파일은 세션과 해상도·주사 방식·프레임률이 같아야 합니다.
- 내부 CG는 원본 템플릿 규격인 **1920×1080, 목표 약 30fps**로 렌더링하며 UHD 세션에서는 확대 합성합니다. 네이티브 4K CG나 59.94fps HTML 렌더링을 의미하지 않습니다. 기존 8-bit UYVY / Rec.709 SDR 출력 경로를 유지합니다.

## 연결 상태

CG 탭에 렌더링 fps가 표시됩니다. 초기 연결이 실패하면 NodeCG를 시작한 뒤 **연결 / 새로고침** 또는 **내부 CG 다시 연결**을 누릅니다. 연결 실패나 그래픽 페이지의 소켓 단절 시 CG를 합성에서 제외하며, 500ms 이상 새 프레임이 전달되지 않아도 배경 영상을 유지합니다.

데이터 연결이 복구되면 기존 CG ON 상태에 따라 합성을 재개합니다. CG를 계속 내려두려면 CG OFF를 누릅니다. NodeCG 서버는 SW를 닫은 뒤에도 실행 상태를 유지하며, SW 내부 렌더러는 세션 정지 또는 SW 종료 시 정리됩니다.

`--diagnostics <파일.json>`을 지정하면 기존 영상·오디오 진단과 함께 `cg.internal`, `cg.fresh`, `cg.rendererFps`, `cg.captureMs`, `cg.sequence` 등을 기록합니다. `fresh`는 합성에 사용할 수 있는 최근 렌더 프레임을 받았다는 뜻이며, 특정 CG가 TAKE되어 보인다는 뜻은 아닙니다.

## NodeCG에 적용된 변경

- 기존 번들의 편집 화면과 그래픽을 사용합니다. `sw-composite.html/js`가 다섯 그래픽을 투명하게 쌓습니다.
- `sw-internal.js` 어댑터와 `cfg/my-cg.json`의 `playoutMode: "internal"` 설정으로 TAKE/OUT의 CasparCG 의존성을 제거합니다. 기존 사용자 데이터와 설정의 다른 항목은 유지합니다.
- 설치 직전 파일은 `Z:\Nodecg\logs\sw-internal-backup-*`에 백업했습니다. 현재 NodeCG 서버를 내부 모드로 재시작했습니다.
- 다른 설치에 적용하려면 패키지 폴더에서 `python scripts/install-internal-cg.py "NodeCG 폴더"`를 실행하고 해당 NodeCG 서버를 재시작합니다.
- 이전 SDI CG 방식으로 돌아갈 때는 `playoutMode`를 `casparcg`로 바꾸고 NodeCG를 재시작한 뒤 CasparCG와 Fill/Key 배선을 사용합니다. SW 상단에서는 SDI Fill/Key를 선택합니다.

## 검증 — 2026-09-24

- 화면에 나타나지 않는 HTML 렌더러에서 투명 배경, 50% 알파, premultiplied RGBA, 애니메이션 진행 확인.
- 5개 CG 유형의 내용 적용/TAKE/OUT을 AMCP 연결 없이 검사.
- 운영 데이터와 분리한 NodeCG 9091 시험 서버에서 실제 HTML → RGBA → GPU → PGM/PVW 경로 확인.
- 실제 1080i 영상 파일 재생 중 CG 합성, PVW/PGM 독립 제어, OUT, 소켓 단절 후 CG 제거 확인. 물리 입출력 포트는 열지 않았습니다.
- 실제 SW 창에서 카드 없는 세션 시작, CG ON/OFF, PVW 단독 표시, 탭 전환 후 합성 유지 확인. 코어·미디어·GPU·라우팅을 포함한 자동 검사 5/5 통과.
- GPU 픽셀 검사: 외부 Fill/Key 및 내부 RGBA, progressive/interlaced, 직접/파이프라인 처리, 투명도, 신호 소실, 잘못된 버퍼 크기 검사.
- 시험 중 1080p HTML 프레임 읽기는 약 12ms였습니다. 전체 방송 체인의 59.94fps 또는 장시간 안정성 보장 수치가 아닙니다. 실제 SDI 출력 시험은 이 작업에 포함하지 않았습니다.

구현 참고: [Qt WebEngine 투명 배경](https://doc.qt.io/qt-6/qwebenginepage.html#backgroundColor-prop), [Qt 위젯 프레임 읽기](https://doc.qt.io/qt-6/qwidget.html#grab).

## UHD 추가 검증 — 2026-09-28

실제 1920×1080 RGBA CG와 3840×2160 progressive 출력 버퍼로 GPU 회귀 검사를 수행했습니다. 직접 처리와 파이프라인 처리 모두 통과했습니다.

- UHD 출력 해상도와 버퍼 크기 확인.
- 네 모서리의 CG 위치, 자막 영역의 정확한 2배 확대, 영역 밖 배경 유지 확인.
- 반투명 알파 합성, PGM/PVW 독립 합성, CG OFF 확인.

따라서 내부 CG는 UHD 세션에도 적용됩니다. CG 원본은 1080p·목표 약 30fps이며 UHD에서는 확대됩니다. 이번 검사는 물리 SDI 출력이나 장시간 프레임률 보장을 검증한 것은 아닙니다. 추가 NodeCG TAKE/OUT 자동 실행은 자동 승인 검토에서 `blocked by policy`로 차단되어 이번 UHD 검증에 포함하지 않았습니다.
