# 통합 CG 스튜디오

기존 CG를 한 화면에서 레이어 단위로 운용합니다. 왼쪽은 레이어 목록, 가운데는 전체 CG 합성 프리뷰, 오른쪽은 선택한 레이어의 설정입니다.

## 열기

- 실행 중인 SW: **CG · NodeCG → 연결 / 새로고침 → 하단 자막 제어의 통합 CG 스튜디오 열기**를 누르세요. NodeCG 대시보드의 **통합 CG 스튜디오** 탭에서도 열 수 있습니다.
- 직접 주소: `http://127.0.0.1:9090/bundles/my-cg/dashboard/studio.html?standalone=true`
- 다음 실행부터 통합 화면을 기본으로 사용하려면 실행 중인 SW를 종료한 뒤 `START-SW.cmd` 또는 `START-CG-STUDIO.cmd`를 실행하세요. 함께 배포한 `sw_switcher-studio.exe`가 통합 화면을 기본으로 엽니다. 기존 `/dashboard/` 주소도 자동 전환하며 사용자 지정 호스트와 포트는 유지합니다.

현재 실행 중인 SW를 강제 종료하거나 서버를 재시작하지 않았습니다.

## 기본 레이어

| 순서 | 레이어 | 설정 |
| --- | --- | --- |
| 1 | 상단 로고 | 이미지 URL, X/Y 위치, 너비·높이, 불투명도, 중앙 프리뷰 드래그 |
| 2 | 날씨 CG | 자동 조회·수동 입력, 지역 전환, 글자·여백·너비 |
| 3 | 프로그램 헤드 | 프로그램명 두 줄 |
| 4 | 자막 | 좌상단 키워드, 파란 리포트, 이름·발언 인터뷰 |
| 5 | 자연재해 스크롤 | 표식, 문구, 스크롤 속도 |
| 6 | 재난 경보 | 기존 분류·문구·출처·테마·속도·글자·위치 |
| 7 | 선거 CG | 기존 개표·후보·사진 설정 |

로고 수치 범위는 기존과 같습니다: X 0~1900, Y 0~1060, 너비 40~800, 높이 20~800, 불투명도 0~100%. 중앙 프리뷰 드래그는 화면 범위 안으로 제한합니다.

## 운용

1. 왼쪽 레이어 이름을 눌러 오른쪽 설정을 엽니다. 레이어를 바꾸어도 각 설정창의 편집 내용은 유지됩니다.
2. 값을 편집하고 아래 **미리보기**를 누릅니다. 로고와 기존 재난 등 원래 자동 프리뷰가 있던 항목은 그 동작을 유지합니다.
3. 가운데 **편집 PVW**에서 확인합니다. 왼쪽 **PVW 체크**는 이 편집 화면에 포함할 레이어만 바꾸며 현재 출력에는 영향을 주지 않습니다.
4. **선택 TAKE**는 선택한 레이어만 켜거나 갱신합니다. **선택 OUT**은 그 레이어만 끕니다. 목록의 ON/OFF가 실제 CG 상태입니다. OFF여도 PVW가 체크되어 있으면 편집 화면에는 보입니다.
5. **현재 CG** 버튼은 실제 CG 출력 상태를 보여줍니다. 중앙 화면의 체크무늬는 투명 영역이며 SW 입력 영상은 포함하지 않습니다. 최종 영상은 SW의 CG PVW로 확인하고 CG ON으로 합성하세요.

**위로 / 아래로**는 레이어가 겹칠 때의 앞뒤 순서를 편집합니다. 목록 위쪽이 앞입니다. 편집 순서는 즉시 PVW에 보이며 **레이어 순서 적용**을 눌러야 현재 CG에도 적용됩니다. 이 버튼은 각 레이어의 TAKE/OUT 상태를 바꾸지 않습니다. 프리뷰 표시 여부와 순서는 저장되어 새로고침 후 복원됩니다.

자연재해·기존 재난 CG를 동시에 표시할 때 프로그램 헤드·자막·날씨는 바 위로 이동합니다. 편집 PVW는 PVW 체크에 맞춰 배치하고 현재 CG는 실제 ON/OFF에 맞춰 배치합니다.

## 검증 및 적용 파일

독립 NodeCG 서버에서 일곱 설정창, 중앙 로고 드래그, 레이어 TAKE/OUT, PVW 표시 및 순서의 출력 격리, 순서 적용, 재난 동시 배치를 확인했습니다. `caption_controls_tests.cjs`, `natural_disaster_tests.cjs`, `studio_layers_tests.cjs`가 통과했습니다.

네이티브 SW 빌드와 UHD 2160p59.94 내부 합성 시험이 통과했습니다. UHD 시험은 TAKE/OUT, PVW·PGM 분리, 연결 끊김 시 CG 제외를 검사했으며 하드웨어 입출력은 열지 않았습니다. 이번 변경에 대한 실제 SDI 송출 시험은 수행하지 않았습니다. CG는 기존 1920×1080 좌표계에서 UHD로 비례 확대합니다.

`scripts/install-broadcast-layout.py`가 화면·그래픽과 통합 탭 등록을 함께 설치합니다. 설치 전 파일은 NodeCG의 `logs/broadcast-layout-backup-*`에 보관합니다. 재난 원본과 서버 확장 코드는 변경하지 않습니다.
