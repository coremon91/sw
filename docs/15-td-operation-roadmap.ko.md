# TD 운용 관점 점검 및 순차 개선

작성일: 2026-10-23. 기준: SW 0.5 소스 검토. 실제 방송 장시간 운용 검증과 구분한다.

현재 프로그램은 영상 합성·입출력 시험 기능을 갖추었으나, 생방송 메인 스위처 운용에는 오조작 방지, 송출 상태 확인, 장애 격리와 복구 기능 보완이 필요하다.

| 1 | 독립 CG ON/OFF | CUT/AUTO가 CG까지 교환하여 카메라 전환 때 자막이 내려가거나 이전 설정으로 바뀔 수 있음 | 배경 전환과 독립된 PGM CG 제어, PVW 편집 격리, 전환 도중 ON/OFF, 상태 표시 및 픽셀 검증 | 0.6 구현·자동 검사 완료, 실제 SDI 운용 검증 대기 |

## 진행 원칙

각 항목을 하나씩 수정하고 검증 결과와 사용법을 기록한 후 GitHub에 반영한다. 이전 배포 폴더는 보존한다. 미구현 항목을 완료로 표시하지 않는다. 실제 SDI 환경 검증 여부를 소프트웨어 테스트와 구분한다.

## 1번 구현 범위 — SW 0.6

- `PVW CG 미리보기`: PVW에서 Fill/Key·반전·불투명도·Premultiplied 설정을 확인한다. PGM에는 즉시 반영하지 않는다.
- `CG ON · PVW 설정 적용`: 현재 PVW CG 설정을 복사하여 PGM CG를 켠다. PVW 미리보기 체크와 별개로 ON 명령을 실행한다. 이미 ON이면 새 PVW 설정을 적용한다.
- `CG OFF`: PGM CG만 끈다. 배경·DVE·PVW 설정을 유지한다.
- CUT/AUTO는 배경·DVE를 전환하고 양 버스 CG 설정을 유지한다. AUTO에서는 배경 합성 뒤 동일 CG를 한 번 적용한다.
- AUTO 중에도 CG ON/OFF가 가능하다. 전환 완료 후에도 마지막 CG 명령이 유지된다.
- ON 버튼은 서로 다른 Fill/Key 입력에 신호가 있을 때 활성화된다. ON 후 신호가 끊어지면 기존 투명 처리와 신호 경고가 적용된다.
- CG 상태 표시는 내부 PGM 합성 상태이며 물리 출력 리턴 검증을 대신하지 않는다.
- CG 시작 상태는 OFF다. 쇼 저장·복원, CG 페이드, NEXT TRANSITION 레이어 선택은 이번 범위에 포함하지 않는다.

## 0.6 검증 결과

- Release 빌드 및 실행 파일 버전 0.6.0.0 확인.
- core, media_fixture, media, routing, cuda_transfer, d3d11_transfer 통과.
- cg_keyfill_gpu: HD/UHD에서 독립 ON/OFF, CUT 후 유지, AUTO 중간 지점 ON/OFF 및 완료 후 유지 검증 통과.
- CG 테스트 초기에는 검사 결과 프레임을 누적 보관하여 출력 풀 한도를 초과했다. 검사 후 프레임 참조를 해제하도록 테스트를 수정한 뒤 해당 검사를 재실행하여 통과했다.
- GUI 고정 레이아웃 및 줄바꿈 검사 통과.
- 기존 0.5 배포 실행 파일 SHA256이 변경되지 않았음을 확인.
- 실제 SDI 방송 세션은 중단하거나 교체하지 않았다. 실제 리턴 화면·장시간 운용은 미검증이다.
