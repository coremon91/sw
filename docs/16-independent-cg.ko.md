# SW 0.6 독립 CG ON/OFF

1. Fill과 Key를 서로 다른 입력에 연결하고 세션을 시작합니다.
2. CG KEY / FILL 패널에서 Fill/Key 입력을 선택하고 `PVW CG 미리보기`를 켭니다.
3. PVW에서 합성 상태를 확인한 뒤 상단 `CG ON · PVW 설정 적용`을 누릅니다. 배경 영상은 그대로 유지됩니다.
4. CUT/AUTO로 배경을 전환해도 PGM CG는 유지됩니다.
5. `CG OFF`를 누르면 PGM 자막만 내려갑니다. AUTO 진행 중에도 사용할 수 있습니다.

송출 중 PVW CG를 편집해도 PGM은 기존 설정을 유지합니다. 수정한 설정을 송출하려면 `CG ON · PVW 설정 적용`을 다시 누릅니다. Key/Fill 신호가 없거나 같은 입력이면 ON 버튼이 비활성화됩니다.

0.5와 달리 CUT/AUTO로 CG를 올리거나 내리지 않습니다. CG ON/OFF는 즉시 전환이며 페이드 기능은 없습니다. CG 상태 표시는 내부 합성 상태로, 실제 SDI 리턴은 별도 확인해야 합니다.

이전 0.3/0.4/0.5 배포는 보존됩니다. 0.6 최초 실행 시 0.5의 저장 설정을 복사하지만 CG ON AIR 상태는 복원하지 않습니다.
