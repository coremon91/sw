# KBC Tech Player 원본 탭

사용자가 지정한 `KBC_Tech_Player_GeForceRTX5060_PORTABLE_20260907` 패키지의 원본 실행 파일을 SW의 **플레이어** 탭에 넣습니다. 실행 파일 SHA-256은 `1A19DECC5C580515E847BAFF6C7057F598EB350D324FFF944F0434658E0D7D03`으로 고정 검증합니다. 원본의 UHD/HD 화면, 파일 탐색기, 재생목록, TC와 전송 조작을 그대로 사용합니다.

## 실행

`dist/SW-player-tab/sw_switcher.exe`를 열고 상단 **플레이어** 탭 → **KBC Tech Player · RTX 5060 · 2026-09-07 원본** → **플레이어 실행**을 누릅니다. `--portable-player` 인수로 실행하면 해당 탭과 원본 플레이어를 바로 엽니다.

패키지의 `player` 하위 폴더에 원본 EXE, DLL 및 `preview_ffmpeg`를 함께 보관합니다. 원본 Z 드라이브 폴더는 수정하지 않습니다. 실행 중 생기는 원본 플레이어 로그는 복사된 `player/logs`에 저장됩니다. SW/원본 플레이어의 FFmpeg DLL은 서로 다른 프로세스와 폴더에서 로드됩니다.

탭을 바꿔도 플레이어 프로세스와 재생은 유지됩니다. **플레이어 종료**는 정상 종료 메시지를 보냅니다. SW를 닫을 때도 SW가 시작한 플레이어에 정상 종료를 요청하며, 별도로 실행한 다른 플레이어는 건드리지 않습니다. 원본에 열린 대화상자나 정지하지 않는 작업이 있으면 원본 창에서 정리할 수 있도록 창을 분리해 둡니다.

SW 전체 종료는 제목 표시줄의 **닫기(X)**를 사용하세요. 원본 창에 키보드 포커스가 있을 때 `Alt+F4`는 원본 플레이어만 닫을 수 있습니다.

## SW 입력 연결

**원본 탭은 화면 통합입니다. 원본 EXE의 DeckLink 출력 기능은 그대로 동작합니다.** 원본에서 재생하는 영상을 SW에 넣으려면 DeckLink 출력 → KONA 입력 같은 SDI 연결이 필요합니다. 원본이 쓰는 출력 포트를 SW 출력 포트와 중복 지정하지 마세요. 세션 시작 전에 각 포트를 확인합니다.

카드 없이 파일을 INPUT 4로 직접 넣는 이전 기능도 같은 플레이어 탭의 **SW 파일 입력 · INPUT 4 직접 연결** 항목에 있습니다. 이 기능과 원본 플레이어의 재생목록·전송 상태는 서로 연동되지 않습니다. 원본 플레이어의 영상·오디오를 메모리로 SW에 직접 전달하는 연결은 별도 소스 변경이 필요하며 이 탭 포장에는 포함되지 않습니다.

## 로컬 패키지 만들기

```powershell
.\scripts\build.ps1
.\scripts\bundle-player.ps1 -PlayerPackage 'Z:\Codex\PORTABLE_RELEASES\KBC_Tech_Player_GeForceRTX5060_PORTABLE_20260907' -Destination dist/SW
```

`scripts/bundle-player.ps1`은 버전 해시를 확인하고 런타임만 복사합니다. 사용자 logs/system_logs와 소스 저장소를 복사하지 않습니다. 원본 바이너리와 nonfree FFmpeg는 로컬 패키지에만 보관하고 GitHub에는 올리지 않습니다.

구현은 SW가 시작한 PID와 원본의 메인 창 클래스를 확인한 후 Qt 외부 창 컨테이너에 연결합니다. 다른 프로세스 창을 이름만으로 찾아 끌어오지 않습니다. 탭을 숨기거나 창 크기를 바꾸면 컨테이너의 표시와 크기를 따릅니다. 스위처 CUT/숫자 단축키는 플레이어 탭에서 비활성화됩니다.
