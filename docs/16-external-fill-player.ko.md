# IN1 외부 Fill + IN4 내부 플레이어 합성

1. Internal 버전 실행 후 세션이 정지된 상태에서 `IN1 Fill + IN4 준비`를 누릅니다.
2. SDI ROUTING의 IN1에 외부 CG Fill이 들어오는 물리 입력을 지정합니다. IN4는 내부 플레이어입니다.
3. 플레이어 탭에서 영상 파일을 선택합니다. HD/UHD 세션과 외부 Fill의 포맷을 맞춥니다.
4. 필요하면 OUT1(PGM), OUT2(PVW)를 선택하고 세션을 시작합니다.
5. 플레이어를 재생하고 `1 · CG 선택`과 `4 · PVW 선택`으로 프리뷰에서 겹침을 확인합니다. 준비 버튼은 CG PVW를 미리 켭니다.
6. `IN1 + IN4 합성 출력`을 누르면 IN4를 배경으로, IN1 CG를 그 위에 PGM 합성합니다. 오디오는 IN4 배경 영상을 따릅니다.
7. `CG OFF · PGM`은 CG만 제거하며 플레이어 배경 영상은 유지합니다.

현재는 Key가 없으므로 Fill의 검은 배경에서 명도 마스크를 만듭니다. CG 내부의 검은색이나 어두운 부분도 투명해질 수 있습니다. 투명 영역이 별도로 지정된 정확한 합성이 필요하면 Key 신호가 필요합니다.

추후 Key 연결: 세션 정지 → 상단에서 SDI Fill / Key 선택 → Fill IN1, Key에 연결한 입력 선택 → 해당 SDI 포트 지정 → 세션 시작. 내부 플레이어는 IN4에 유지합니다.

검증: 코어 및 GPU 합성 테스트, 단일 Fill의 투명/불투명/신호 끊김/PGM-PVW 분리, 내부 모드 외부 Fill/Key 입력 선택 UI 통과. 실제 외부 SDI 송수신은 별도 확인 필요.
