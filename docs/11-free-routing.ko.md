# SW 0.3 · 입출력 자유 선택 + CG Key/Fill

SESSION / SDI ROUTING에서 실제 SDI · 입출력 자유 선택을 고릅니다.
IN 1~4마다 DeckLink 또는 KONA 입력 포트를 지정하거나 사용 안 함을 선택합니다.
OUT 1 / PGM, OUT 2 / PVW마다 원하는 출력 포트를 선택할 수 있습니다.
LOCAL · SDI 출력 안 함을 선택하면 해당 SDI 출력은 열지 않고 화면에만 표시합니다.
입력은 최소 1개 필요하고, 출력은 0개/1개/2개 모두 가능합니다.
포트 선택은 정지 상태에서 변경하며, 세션 시작 시 저장합니다.
같은 물리 채널을 두 입력 또는 입력/출력에 중복 지정할 수 없습니다.
카드가 현재 프로파일에서 제공하는 입력/출력 방향과 포맷만 사용합니다.
포트를 입력/출력으로 배정하는 기능이며 카드 펌웨어/프로파일을 자동 변경하지 않습니다.

예: IN1=영상, IN3=CG Fill, IN4=CG Key, IN2=사용 안 함,
PGM=KONA SDI 1, PVW=LOCAL. 다른 카드 조합과 반대 방향도 가능합니다.
CG 패널에서 Fill=INPUT 3, Key=INPUT 4를 선택하고 CG 합성 사용을 켠 뒤
PVW를 확인하여 CUT/AUTO 합니다. Key/Fill도 기존 4입력 슬롯을 사용합니다.
모든 입력은 세션 포맷과 같아야 하고, CG Fill/Key는 동기된 신호가 필요합니다.
CG 세부 사용법은 CG-KeyFill-사용안내.md를 참고하세요.
