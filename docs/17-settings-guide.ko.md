# SW 설정 및 운용 GUIDE

입출력 모드·포맷, IN 1~4, PGM/PVW 출력, 장치 검색, 세션 시작/정지는 **설정 → 입출력 라우팅**에서 조작합니다. 설명은 **설정 → 사용 가이드**에 있습니다. 스위처 화면의 **입출력 설정** 버튼으로 바로 이동할 수 있습니다.

## 1. 방송 시작 전 확인

1. 설정 → 입출력 라우팅의 SESSION / SDI ROUTING에서 실제 SDI 모드와 HD/UHD 포맷을 선택합니다.
2. IN 1~4에 입력을 배정하고 OUT 1 / PGM, OUT 2 / PVW에 출력 포트를 선택합니다. 같은 포트를 중복 지정할 수 없습니다.
3. 세션을 시작한 후 입력 신호, PVW, PGM을 확인합니다. LOCAL 표시는 물리 SDI 출력이 없는 상태입니다.
4. 출력 음소거 체크와 외부 모니터의 영상·오디오를 확인합니다. GUI PGM은 내부 합성 화면이며 SDI 리턴 화면이 아닙니다.

세션 중에는 입출력 포맷과 포트 변경이 잠깁니다. 변경하려면 세션을 정지해야 하며 출력이 중단됩니다. 현재 정지 버튼과 창 닫기는 즉시 세션을 종료하므로 운용 중 주의하십시오.

## 2. 배경 전환 — CUT / AUTO

- 입력 아래 PVW 선택 버튼으로 다음 배경을 준비합니다.
- CUT은 배경과 DVE를 즉시 전환합니다. AUTO는 지정한 frames 동안 전환합니다.
- 30 frames는 HD 29.97fps에서는 약 1초, UHD 59.94fps에서는 약 0.5초입니다.
- 숫자 1~4: PVW 선택 / Space: CUT / Enter: AUTO. 스위처 탭에서 사용하며 입력 편집 중에는 단축키가 제한됩니다.
- AUTO 중에는 배경·DVE·PVW CG 편집이 잠기지만 독립 CG ON/OFF는 가능합니다.

## 3. 독립 CG ON/OFF

1. CG Fill과 Key를 서로 다른 입력에 연결합니다. 두 신호는 같은 포맷과 동기가 필요합니다.
2. CG KEY / FILL 패널에서 입력을 지정하고 PVW CG 미리보기를 켜서 확인합니다.
3. CG ON · PVW 설정 적용을 누르면 현재 PVW의 CG 설정을 PGM에 복사하여 자막을 올립니다. PVW 미리보기 체크와 별개인 송출 명령입니다.
4. CG OFF는 PGM의 CG만 내립니다. 배경과 PVW 설정은 유지됩니다.

CUT/AUTO는 CG를 올리거나 내리지 않습니다. 배경 전환 중에도 CG가 유지됩니다. PGM CG가 켜진 상태에서 PVW를 편집해도 송출 설정은 바뀌지 않습니다. 변경 내용을 적용하려면 CG ON을 다시 누릅니다.

- Key 검정: 배경 노출 / Key 흰색: Fill 노출. Key 반전 사용 시 반대입니다.
- Premultiplied Fill: CG 장비가 미리 알파를 곱한 Fill을 출력할 때 사용합니다. 장비 출력 방식과 맞춰야 합니다.
- CG ON 버튼 비활성: 세션 정지, 동일한 Fill/Key 입력, 또는 입력 신호 없음 여부를 확인합니다.
- CG ON AIR는 내부 합성 상태입니다. 실제 SDI 출력은 외부 리턴으로 확인합니다.
- CG 페이드와 Key/Fill 프레임 자동 짝맞춤은 아직 제공하지 않습니다.

## 4. 미리보기 갱신 속도

미리보기 갱신 선택과 실제 fps 표시는 설정 → 입출력 라우팅에만 있습니다. 59.94 / 29.97 / 14.985fps를 선택하고 설정 저장을 누르면 다음 실행에도 복원됩니다.

높은 값은 스크롤 움직임을 더 자주 보여주지만 GPU 읽기와 GUI 부하가 늘어납니다. 선택값은 목표 속도이며 실제 값은 설정 탭의 갱신 선택 옆에서 확인합니다. SDI 출력 포맷 자체는 바뀌지 않습니다. 출력 드롭이 늘면 낮은 갱신율로 비교하십시오.

## 5. 오디오 상태값 — 입력 부족 / 버퍼 초과

두 수치는 영상 입력 개수가 아니라 입력 오디오 큐 상태입니다. 입력 4개의 합계이며 세션 중 누적됩니다. PGM에서 사용하지 않는 입력도 포함되고, 출력 음소거 상태에서도 집계됩니다.

| 화면 표시 | 의미 | 발생 시 처리 |
|---|---|---|
| 입력 부족 | 재생 중 필요한 오디오 분량을 확보하지 못한 횟수 | 해당 구간 무음 출력 후 재버퍼링 |
| 버퍼 초과 N samples | 버퍼 한도를 넘어 버린 스테레오 샘플 프레임 수 | 가장 오래된 오디오 제거 |
| 오디오 부족 | 입력 부족과 같은 누적 카운터 | 별도의 추가 오류가 아님 |
| 출력 시계 복구 | 출력 장치의 시계에 맞춰 스케줄을 재조정한 누적 횟수 | 코드의 출력 복구 동작 |

입력 버퍼 한도는 48kHz 기준 약 100ms입니다. 초기 또는 부족 후에는 필요한 출력 분량에 20ms 여유분을 더 확보한 뒤 재개합니다. 초기 버퍼 대기 무음은 입력 부족 횟수에 포함되지 않습니다.

예: 입력 부족 10은 부족 감지 10회입니다. 버퍼 초과 4800은 합산 100ms의 오디오 분량을 버렸다는 뜻이며, 한 번에 100ms가 끊겼다는 뜻은 아닙니다. 서로 다른 입력의 합계이므로 특정 PGM의 손실 시간으로 해석하면 안 됩니다.

값이 남아 있는 것보다 계속 증가하는지를 보십시오. 현재 화면은 입력별 원인과 PGM 영향 여부를 구분하지 않으므로 이 수치만으로 방송 오디오 장애나 GPU 부족을 단정할 수 없습니다.

## 6. 영상 상태와 지연 해석

- NO SIGNAL: 해당 입력 신호 상태를 확인하십시오. 배선, 포맷, 장비 출력을 점검합니다.
- I/O 드롭: 장치 통계의 드롭 합계입니다. 어느 포트에서 증가했는지 추가 진단이 필요합니다.
- 마감 초과(누적): 처리 마감 시각을 넘긴 횟수입니다. ms 단위의 종단 간 지연이 아닙니다.
- 처리 ms: 엔진 한 주기의 처리 시간입니다. 입력 장비부터 최종 모니터까지의 전체 지연을 뜻하지 않습니다.
- GUI에서만 끊기는지 SDI 리턴에서도 끊기는지 구분합니다. CG는 Fill 원본과 Key 원본도 확인합니다.

## 7. 파일 플레이어와 설정 보존

내장 플레이어는 INPUT 4를 사용합니다. 세션 포맷과 일치하는 파일을 선택한 후 CUE, 재생, PVW 확인, CUT/AUTO 순서로 운용합니다. 실제 출력 오디오도 별도로 확인합니다.

설정 → 입출력 라우팅에서 **설정 저장**을 누르면 현재 구성을 이 PC에 저장합니다. **저장 설정 불러오기**로 되돌릴 수 있으며, 다음 프로그램 실행에도 마지막으로 명시적으로 저장한 구성이 복원됩니다. 변경 후 유지하려면 설정 저장을 다시 누르세요.

저장 대상: 입력 1~4와 PGM/PVW 출력 포트, 소스 모드, HD/UHD 포맷, 미리보기 갱신 속도, AUTO 전환 프레임 수, 출력 음소거, 내장 플레이어 사용 여부·파일 경로·반복 여부, 로그 기록 사용 여부입니다.

실행 중에는 저장은 가능하고 불러오기는 잠깁니다. 불러오기는 세션을 자동 시작하지 않습니다. 연결되지 않은 저장 포트는 장치 없음으로 표시되며 임의의 다른 포트로 대체하지 않습니다. 장치를 연결하고 다시 검색한 뒤 확인하십시오.

CG/DVE 설정, CG ON AIR, 배경 선택, 세션 실행 상태와 플레이어 재생 상태는 저장·복원하지 않습니다. CG는 시작 시 OFF입니다. 전체 쇼 파일의 저장·내보내기는 후속 기능입니다.

0.7.x는 같은 사용자 설정 저장소를 사용합니다. 저장 위치는 Windows 사용자 레지스트리 `HKEY_CURRENT_USER\Software\SW\Switcher-0.7`의 `routingPreset` 값이며, JSON 형식의 설정 한 세트를 Qt QSettings로 저장합니다. 프로그램 폴더의 쓰기 권한 없이도 저장할 수 있습니다. 형식이 잘못된 저장 데이터는 적용하지 않습니다.

## 8. 순차 개선 현황

독립 CG ON/OFF는 구현되었습니다. 방송 중 정지·종료 잠금, 출력 경보, 입력 장애 격리, Key/Fill 동기 보강, 출력 우선 처리, 전체 쇼 저장과 오디오 운용 개선은 후속 항목입니다.

설정 탭을 열거나 가이드 검색을 하는 동작은 방송 세션을 정지하지 않습니다.

## 9. 재생 / 세션 로그

설정 → 입출력 라우팅의 **재생 / 세션 로그 기록**이 기본으로 켜져 있습니다. SDI 세션 또는 SW 내장 플레이어 세션을 실행하면 약 1초마다 JSONL 파일에 진단 값을 기록합니다. 로그 폴더 열기로 저장 파일을 확인할 수 있습니다. 외부 KBC Tech Player 프로세스 내부의 재생 진단은 포함하지 않습니다.

- 기록 항목: UTC 시각, 세션 시작·종료, 입력/출력 포트, 입력 신호·fps·오디오 버퍼, PGM/PVW 선택, CG 활성 상태, 미리보기 fps, 처리 시간, I/O 드롭, 오디오 부족·버림, 파일 플레이어 상태와 오류.
- 영상·음성 원본은 녹화하지 않습니다. 파일 플레이어 경로는 설정 저장에 포함되지만 주기 로그에는 기록하지 않습니다.
- 1초 표본과 누적 카운터이므로 짧은 모든 조작의 순서를 추적하는 이벤트 로그는 아닙니다. 화면이 응답하지 않는 동안에는 로그도 지연될 수 있습니다.
- 기록 실패는 설정 탭에 표시하며 방송 엔진을 중단하지 않습니다. 실패 후 같은 세션에서 재시도하려면 기록 체크를 껐다 켭니다.
- 로그는 Windows 사용자 로컬 앱 데이터의 `SW/Switcher-0.7/logs`에 저장합니다. 각 파일은 약 20MB마다 새 파일로 분할하며 기존 파일을 자동 삭제하지 않습니다. 디스크 공간은 주기적으로 확인하십시오.
- 정상 종료 시 마지막 상태를 기록합니다. 강제 종료나 전원 차단 시 마지막 구간은 누락될 수 있습니다.
