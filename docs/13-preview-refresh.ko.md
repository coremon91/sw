# SW 0.5 미리보기 갱신

스위처 상단의 `미리보기 갱신`에서 59.94 / 29.97 / 14.985 fps를 선택합니다.
기본값은 59.94fps이며 실행 중 변경할 수 있고 다음 실행에도 유지됩니다.
실제 달성 속도는 하단의 미리보기 fps로 확인합니다. 높은 갱신 속도는 GPU 읽기와 GUI 부하를 늘리므로 출력 드롭이 증가하면 29.97 또는 14.985fps로 낮춰 비교합니다.

0.4의 D3D11 합성, CUDA 전송, 480×270 RGBA 미리보기 및 Qt 표시 방식을 유지합니다. FFmpeg 인코딩/디코딩 단계를 추가하지 않습니다. SDI 출력 포맷·출력 스케줄은 변경하지 않습니다. 이 변경만으로 실제 SDI 출력 끊김 해결을 보장하지 않습니다.

0.5는 별도 폴더에 빌드하며 0.3/0.4 실행 파일을 덮어쓰지 않습니다. 최초 실행 시 0.4 설정을 복사한 후 독립적으로 저장합니다.

빌드: `scripts/prepare-cuda.ps1`로 CUDA 의존성을 준비한 후 `scripts/build.ps1 -DependencyRoot <기존 SW 의존성 폴더>`를 실행합니다.
