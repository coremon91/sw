# 양방향 수신 시험과 화면 떨림 확인

## 실행

이번 시험용 배포 폴더는 `dist/SW-receive-v2`입니다. 기존 실행 파일을 사용하는 창을 정지한 뒤 새 폴더의 실행기를 사용하세요.

| 시험 방향 | 실행기 | 외부 플레이어 출력 | SW 입력 |
|---|---|---|---|
| 기존 방향 | `DeckLink-receive.cmd` | KONA 5 | DeckLink 8K Pro |
| 반대 방향 | `KONA-receive.cmd` | DeckLink 8K Pro | KONA 5 |

1. 외부 플레이어 출력을 **3840×2160p59.94**, Single Link 12G-SDI로 맞추고 출력 포트와 수신 카드의 입력 포트를 연결합니다.
2. 같은 포트를 사용하는 기존 SW 수신 세션을 정지합니다. 반대 방향에서는 KONA 출력 플레이어도 종료하여 카드 점유를 해제합니다. 이 SW가 외부 플레이어의 출력 카드를 바꾸지는 않습니다.
3. 원하는 수신 실행기를 열고 UHD 세션과 실제 연결된 입력 **한 개**를 지정합니다. 다른 IN은 `사용 안 함`으로 둡니다. 제조사 이름 뒤 번호와 실제 BNC 매핑을 확인하세요.
4. 세션을 시작하면 선택한 입력이 INPUT과 LOCAL PGM/PVW에 표시됩니다. 선택한 제조사의 입력만 열고 물리 출력은 생성하지 않습니다.
5. HD 시험은 양쪽을 **1080i29.97 / 59.94 fields**로 바꿉니다. UHD와 HD를 동시에 출력하지 않습니다.

KONA SDK가 없는 빌드는 KONA 입력을 열 수 없습니다. 카드 사용 중이면 점유 오류를 표시하며 다른 프로그램의 스트림을 강제로 중단하지 않습니다.

## 진단 표시

- 입력의 FPS/frames: 유효 캡처 프레임 수와 최근 약 1초의 평균 수신 속도. UHD 목표 59.94fps, HD 목표 29.97fps.
- 화면 처리 FPS: GPU가 만든 모니터 영상 묶음 수. 목표 59.94회/초이며 실제 디스플레이 주사율/표시 FPS와 다릅니다. HD에서는 필드 단위입니다.
- 입력 드롭/무신호: 어댑터가 보고한 누락과 무효 신호 횟수. SDK별 의미가 달라 SDI 케이블 오류 수와 동일하지 않습니다.
- 모니터 생략: 최신 프레임을 선택하는 과정에서 소비하지 못한 캡처 시퀀스 수. GUI/디스플레이의 모든 누락을 측정하는 값은 아닙니다.
- 처리 지연: 호스트 처리 시간이 해당 틱의 마감을 넘긴 횟수.

`sw_probe.exe`는 카드 설정을 바꾸지 않고 JSON으로 장치 상태를 출력합니다. DeckLink의 `signal`, `detected`, `scan`, `link`와 KONA의 `ownerPID`, `direction`, `detected`를 확인할 수 있습니다. 검색 당시 상태이며 세션 중의 연속 신호 무결성을 보증하지 않습니다.

## 조사 결과와 수정

2026-09-10 기존 방향의 드라이버 조회에서는 DeckLink 8K Pro (4)가 **2160p59.94 / progressive / single link / signal locked**를 보고했습니다. 다른 세 입력은 신호가 없었습니다. 약 10.8초간 6회의 실제 SW 창 관찰에서 영상 영역 경계는 고정되어 있었고 수신 표시는 약 60fps였습니다. 간헐적인 캡처이므로 빠른 수직 떨림의 유무나 원인을 확정하지 않습니다.

코드에서는 다음 표시 문제를 확인하여 수정했습니다.

1. 기존 수신 모니터 생성은 약 15fps, Qt 갱신은 10fps로 제한되어 있었습니다. 수신 모드에서 매 59.94Hz 틱에 모니터를 만들고 Qt 정밀 타이머를 16ms로 바꿨습니다. 제어판 갱신은 약 100ms 간격으로 분리했습니다.
2. UHD를 480×270으로 축소할 때 단일 bilinear 샘플을 사용했습니다. 모니터에 4×4 다중 bilinear 샘플 필터를 적용하고 Qt 확대 표시도 부드러운 보간을 사용합니다. 물리 출력의 픽셀 경로는 이 축소 필터를 적용하지 않습니다.
3. 하단 상태 문구 줄바꿈에 따라 영상 영역이 재배치될 수 있었습니다. 상태 영역 높이를 고정했습니다. 이것이 사용자 관찰 구간의 직접 원인으로 확인된 것은 아닙니다.
4. KONA 수신 모드를 추가하고 Windows 수신 수직 이벤트 구독, 카드별 포트 검증, 제조사별 설정 저장을 포함했습니다.

현재 구성의 수직 떨림을 두 카드의 공통 레퍼런스 부재로 확정하지 않습니다. AJA SDK의 capture4k 예제도 수신 전용 앱에서는 SDI 출력 클럭/레퍼런스 설정이 중요하지 않다고 설명합니다. 다입력 프레임 동기화와 물리 PGM/PVW 출력 젠록은 별도 미완료 항목입니다.

## 검증

- HD/UHD GPU 픽셀 검사, 파이프라인 순서, progressive 틱 간 고정 이미지 불변, UHD 체크보드 축소 검사 통과.
- 모니터 전용 UHD 입력 한 개의 패턴 생성·업로드·필터·리드백 평균 4.27ms, 최대 5.22ms. 실제 SDI 전체 지연 측정값은 아닙니다.
- Qt 레이아웃 검사에서 기존 가변 높이 상태 영역의 영상 이동을 재현하고, 고정 후 3개 창 너비에서 영상 영역 불변을 확인했습니다.
- 사용자는 반대 방향에서 상하 흔들림이 사라졌다고 보고했습니다. 이어진 전체 SDI 모드의 KONA 수신·DeckLink 출력 및 오디오 점검은 [오디오 시험 기록](07-audio-validation.ko.md)에 정리했습니다. 원래 방향의 떨림 원인이 최종 확정된 것은 아닙니다.

UHD 4입력·2출력 전체 부하와 장시간 실신호 검증은 별도입니다.
