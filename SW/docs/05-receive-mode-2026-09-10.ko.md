# 2026-09-10 외부 플레이어 수신 확인 모드

시험 경로는 외부 4K 플레이어 → KONA 5 SDI 출력 → 12G-SDI 케이블 → DeckLink 8K Pro 입력 → SW 화면입니다.

- `DeckLink 수신 확인 · 출력 없음`에서 입력 1–4개를 선택할 수 있습니다. 나머지 입력은 열지 않습니다.
- 이 모드에서는 DeckLink만 검색·캡처합니다. KONA와 물리 출력 어댑터는 열지 않습니다.
- 첫 선택 입력을 LOCAL PGM/PVW에 표시합니다. CUT/DVE는 화면에서 확인할 수 있습니다.
- 유효 수신 프레임 수와 최근 약 1초의 수신 fps를 표시합니다. GPU 모니터는 약 15fps로 갱신합니다.
- 전체 해상도 출력 버퍼 생성과 리드백은 생략합니다. 수신 전용 부하를 이전 UHD 4입력·2출력 엔진 측정과 동일시하지 않습니다.
- DeckLink의 사용 중 상태를 표시하고 이미 캡처 중인 입력은 시작하지 않습니다. 실패한 시작을 정리할 때 해당 인스턴스가 성공적으로 활성화한 스트림만 해제합니다.

## 검사

Release 빌드와 CTest 2개 통과. 수신 포트 검사는 입력 한 개/임의 슬롯을 허용하고, 빈 선택·중복·AJA 입력·미지원 포맷·출력 전용 포트를 거부했습니다. UHD GPU 검사에서 모니터 전용 경로가 화면은 생성하면서 두 출력 버퍼는 생성하지 않는 것을 확인했습니다. Qt 수신 설정 화면과 한글 표시를 확인했습니다.

실제 수신 시작 검사에서는 DeckLink 네 채널 모두 `capture=busy`를 반환했습니다. 기존 SW 창과 KONA 플레이어가 실행 중이었습니다. 다른 캡처를 중단하지 않고 새 수신 시작을 거부했습니다. 특정 프로세스가 각 채널을 소유하는지는 SDK의 busy 값만으로 확정할 수 없습니다. **이번 변경에서 실제 영상 수신 성공은 아직 확인하지 못했습니다.**

기존 스위처에서 정지 후 종료하고 `dist/SW-receive/DeckLink-receive.cmd`로 새 설정 화면을 엽니다. KONA 플레이어를 3840×2160p59.94로 재생한 상태에서 케이블이 연결된 DeckLink 입력을 선택하고 세션을 시작하세요. 다른 플레이어 프레임 레이트는 자동 감지·변환하지 않습니다. 기존 KONA 출력용 `UHD-loopback.cmd`는 함께 실행하지 않습니다.
