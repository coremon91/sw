# SW — Software Video Switcher

Vizrt TriCaster의 제작 흐름을 참고하는 HD/UHD 소프트웨어 비디오 스위처 프로젝트입니다.

현재 단계는 **요구사항 및 기술 타당성 검토**입니다. 실제 SDI 입출력 엔진은 아직 구현되지 않았습니다.

## 확인된 요구사항

- 레퍼런스: Vizrt TriCaster.
- 기본 DVE: PIP, 위치·크기 조절, 크롭 등을 포함하는 방향.
- 동시 영상 입력 4개, 동시 출력 최소 2개.
- 출력 역할: OUT 1 = 프로그램(PGM), OUT 2 = 미리보기(PVW). 서로 다른 영상을 동시에 내보내는 두 출력.
- UHD 모드: 3840×2160, 59.94p (`60000/1001` 프레임/초).
- HD 모드: 1920×1080, 29.97i (`30000/1001` 프레임/초, `60000/1001` 필드/초). 장비의 `1080i59.94` 표기와 같은 포맷.
- 세션에서 UHD 또는 HD 한 포맷을 선택하며, UHD와 HD를 동시에 출력하지 않음.
- 사용할 카드: AJA KONA 5, Blackmagic DeckLink 8K Pro.
- GitHub 저장소: [coremon91/sw](https://github.com/coremon91/sw) — 사용자가 생성한 공개 저장소.

## 기술 검토 결론

**C++ 영상 엔진 + Qt 6 데스크톱 UI + GPU 합성**을 권장합니다. Windows 11 x64를 우선 검토 대상으로 삼았습니다. 운영체제와 세부 구현 구성은 설계 제안이며, 4입력·최소 2출력 및 위 영상 포맷은 사용자 확정 요구사항입니다.

물리 SDI 4입력·2출력을 최소 구현 목표로 잡습니다. 우선 후보는 DeckLink 8K Pro의 4입력과 KONA 5의 PGM/PVW 2출력입니다. KONA 5에서 서로 다른 UHD 영상 두 개를 동시에 출력할 수 있는지는 실제 SDK 장치 능력과 펌웨어를 확인한 뒤 확정합니다.

## 현재 코드의 범위

`index.html`, `src/main.js`, `src/style.css`는 기존 웹 화면 시안입니다. 카드 이름, 연결 상태, 영상, 오디오 미터, ON AIR와 녹화 표시는 모의 데이터입니다. 실제 카드 검색, SDI 입출력, 영상 DVE, 녹화 또는 스트리밍 기능을 제공하지 않습니다.

화면의 TAKE/AUTO 조작도 브라우저 화면 상태를 바꾸는 동작입니다. 이 코드는 조작 화면을 검토하는 자료로 보존하며, 방송 장비의 동작 확인에 사용하지 않습니다. `package.json`의 기존 버전 값은 네이티브 스위처의 출시 버전을 의미하지 않습니다.

## 버전 관리

검토 문서와 기존 화면 시안을 초기 Git 이력으로 관리합니다. 향후 기능 개발은 `codex/<작업명>` 브랜치에서 진행하고, 검증 결과를 남긴 뒤 기준 브랜치에 반영합니다.

제조사 SDK 설치물, 빌드 산출물, 실제 방송 영상 및 로컬 자격증명은 커밋 대상에서 제외합니다. SDK·드라이버·펌웨어의 실제 시험 조합은 개발 단계별로 기록합니다.
